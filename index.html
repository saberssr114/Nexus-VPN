      Windows Guide
      
Setup on Windows

      
Connect in 60 seconds using Windows built-in VPN (IKEv2/L2TP) or install our NexusVPN client for one-click access.

    


    

      

        

          
01

          

            
Open Network Settings

            
Press Win + I, go to Network & Internet → VPN, then click Add a VPN connection.

          

        

        

          
02

          

            
Enter Server Details

            
Select Windows (built-in) as provider. Choose IKEv2 as VPN type. Enter the server address from any code above.

          

        

        

          
03

          

            
Enter Credentials

            
Use the username and password from the VPN code card. Leave pre-shared key blank for IKEv2.

          

        

        

          
04

          

            
Connect & Verify

            
Click Save, then select your new VPN in the VPN list and click Connect. Check your IP has changed at whatismyip.com.

          

        

      


      

        

          
          PowerShell Quick Setup
        

        
# NexusVPN — Windows PowerShell Quick Setup
# Run as Administrator

$vpnName = "NexusVPN-US"
$serverAddr = "us-nyc-01.nexusvpn.io"
$pskKey = "NxV!2024#SecureKey"

# Add VPN Connection
Add-VpnConnection `
  -Name $vpnName `
  -ServerAddress $serverAddr `
  -TunnelType "Ikev2" `
  -EncryptionLevel "Maximum" `
  -AuthenticationMethod "MSChapv2" `
  -RememberCredential `
  -PassThru

# Set DNS for VPN
Set-VpnConnectionIPsecConfiguration `
  -ConnectionName $vpnName `
  -AuthenticationTransformConstants SHA256128 `
  -CipherTransformConstants AES256 `
  -DHGroup Group14 `
  -IntegrityCheckMethod SHA256 `
  -PfsGroup None `
  -EncryptionMethod AES256

Write-Host "✅ NexusVPN configured successfully!" -ForegroundColor Green
Write-Host "🔗 Connect: rasdial '$vpnName' vpnuser yourpassword"
